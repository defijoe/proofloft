## Factory — next products (strategy set Aug 20, 2026)

Principle: every new product reuses the same buyer (agencies/SMBs), the same engine (collect → approve → display, consent records, magic-link auth, zero-SDK Stripe, Resend email), and the same distribution. Ranked:

1. **Proofloft distribution first.** No new product until Proofloft has its first real agencies — everything below doubles in value once there's a customer base to cross-sell.
2. **ReviewLoft — 🚀 LIVE at [getreviewloft.com](https://getreviewloft.com) (Aug 21, 2026).** Review funnel for local businesses: 4–5★ routes to "post it on Google," 1–3★ routes to a private feedback inbox (every rater can still reach Google — compliant with Google's review policies). **Billing LIVE (Aug 23):** $49/mo per location (price_1U7bJS4I71kjhJGUyyifBNyu) or $490/yr (price_1U7bJZ4I71kjhJGUKNZEbIV7), product prod_V7r1vUpbejdo0a, webhook we_1U7bJg4I71kjhJGUuOUaaKZM → /api/billing/webhook; all four STRIPE_* envs set in Netlify by Jon. Model: **30-day free trial, NO card required** (Checkout `payment_method_collection=if_required` + `trial_settings.end_behavior.missing_payment_method=cancel`; first-time subscribers only — anyone with a prior subscriptions row pays day one; customer adds card via Manage billing portal or Stripe's 7-day trial-ending reminder email, which Jon enabled), quantity = one seat per location (min 1), auto-synced with prorations on add/delete; lapsed/canceled accounts keep their live funnel pages and QR codes working, dashboard gates adding/managing until reactivation. (Model evolved Aug 23–24: first-location-free-forever → card-upfront trial → no-card trial, per Jon.) **MIGRATED to its own Stripe account Aug 24: acct_1U7bqnKkftE3Narf "Reviewloft.com"** (fully activated, bank verified, ReviewLoft branding + statement descriptor REVIEWLOFT set): product prod_V84QrQNDSAtU7h (tax_code txcd_10103001 — REQUIRED on this account, Stripe Tax on; missing tax code was one checkout blocker), monthly price_1U7oIAKkftE3Narfl2GdSctH, annual price_1U7oJ4KkftE3NarfATlyRmFy, webhook we_1U7oJDKkftE3Narfk6jWHIIa. Debug lessons from the Aug 24 outage: envs pointed at mixed accounts + a bad secret key + the Stripe whsec pasted into RESEND_WEBHOOK_SECRET (all fixed; Resend secret restored); Netlify function logs (Logs → Functions) are the fastest way to see the real Stripe error. **Checkout-success sync added (Aug 24):** success_url carries {CHECKOUT_SESSION_ID}; dashboard pulls the subscription via `syncCheckoutSession()` on return so "Pro" shows immediately without racing webhook delivery (also handles new flexible-billing API where current_period_end lives on the subscription item). Verified end-to-end by Jon: no-card trial checkout → trialing sub → Pro dashboard. NOTE: new account = new API version; old Proofloft-account webhook pointing at getreviewloft.com should be deleted if not already. **Homepage v2 + Tailwind + orange CTA shipped Aug 25** — see UI & QA log above. White-label through agencies is the cross-sell. Repo: trendinux/reviewloft · Neon DB `reviewloft` · Netlify site `reviewloft`. 3. **Client report sender for agencies** — branded monthly "what we did + results" report pages with view receipts. Same buyer as Proofloft; best cross-sell.
